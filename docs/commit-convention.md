# Git 提交规范

本项目提交信息遵循 Conventional Commits，统一使用中文。

## 格式

```
<type>(<scope>): <简述>

<可选正文：简短要点>
```

### type（语义化类型）

- `feat` 新功能
- `fix` 修复缺陷
- `docs` 文档变更
- `style` 代码格式（不影响逻辑）
- `refactor` 重构（非新增功能、非修复）
- `perf` 性能优化
- `test` 测试相关
- `chore` 构建 / 工具 / 杂项
- 其他约定俗成的类型亦可

### scope（可选）

表示影响范围，通常为模块名，如 `presets`、`scheduler`、`device`、`clicker`、`cli`。

### 正文（可选）

- 空一行后用简短要点，每点一行
- 聚焦"改了什么"，精炼，不写客套或解释性话术
- 简单改动只写首行即可

## 示例

```
feat(presets): 预设坐标增删查与 JSON 读写

- 支持损坏文件容错
- 文件路径参数化便于测试
```

```
chore: 重构项目脚手架

- 切换到 Python 3.12.12
- 移除 abd、adbutils 无用依赖
```

```
fix(cli): 修复定时模式倒计时换行

- 倒计时结束后补一个换行
```
